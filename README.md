# The Girl

Autonomous AI agent deployed into Solana's agentic economy as artistic research.

## Structure

- `src/plugins/` — ElizaOS plugins (ledger, soul, avatar, weekly reckoning)
- `knowledge/facts/` — live ledger files (price, relation, consumption)
- `protocols/` — weekly diary entries, spell/body choices, data exports
- `alambic/decision_log/` — architectural decisions

## Data

`protocols/` and `knowledge/facts/` are updated automatically each week by The Girl.

*Private. Runs October 2026 – April 2027.*
